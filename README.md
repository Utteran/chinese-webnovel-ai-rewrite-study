# 中文网文 AI 仿写识别：词汇与句法信号研究

**Chinese Web-Novel AI Rewrite Study** · 探索性科研项目

这个仓库研究一个有限的问题：在**中文网络小说风格模仿重写**任务中，词汇统计与句法序列各能提供多少区分信号？实验将同一段人工原文与 DeepSeek 仿写文本配对，比较句法 Transformer、词汇 XGBoost 及两者的融合。

网页和 API 的分数只表示模型在当前实验设定下对“仿写类”的倾向；即使经过验证集校准，也不能解释为真实文本由 AI 生成的概率，更不能证明作者身份或文本来源。详细边界见 [研究设计](docs/RESEARCH.md) 和 [模型说明](docs/MODEL_CARD.md)。

## 当前证据

V2 使用 442 对原文／仿写文本，按书分成 295 对训练、61 对验证、86 对测试。下表来自仓库现有的 [融合报告](reports/v2/fusion_report.json)，单位是**段落样本**，测试集共 172 段：

| 方法 | 测试 AUC | 准确率 | F1 | 人类原文误报率 | 仿写检出率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 句法 Transformer | 0.829 | 73.8% | 74.9% | 30.2% | 77.9% |
| 词汇 XGBoost | 0.970 | 91.9% | 92.0% | 9.3% | 93.0% |
| 校准后融合 | 0.981 | 91.9% | 92.0% | 9.3% | 93.0% |

在这个测试集上，融合提高了 AUC，**没有提高表中的准确率、F1 或检出率**。权重搜索对测试集进行了多方案比较，因此这些结果应视为探索性结果；仓库尚无独立的最终外部测试集。V1 与 V2 的数据构造不同，不能把两版 AUC 直接当作模型进步幅度。[实验设计与风险](docs/RESEARCH.md) 说明了选择偏差、分组相关性和泛化范围。

## 从仓库开始

只检查已提交数据，无需下载模型或安装机器学习依赖：

```bash
python scripts/audit_dataset.py
python -m unittest discover -s tests -v
```

审计会检查 V1/V2 配对 ID、标签、书籍划分、句法序列与词汇特征对齐，以及跨划分的完全重复文本。它不能排除语义近重复、作者重叠或来源偏差。

训练及网页推理需要先安装 [requirements.txt](requirements.txt) 中的依赖。模型权重约 950 MB，**未提交到仓库**；须按 [复现说明](docs/REPRODUCIBILITY.md) 训练或从作者处取得。缺少权重时，网页/API 无法启动；现有报告和数据审计仍可查看。

## 研究边界

- 只有一个生成模型和一种主要仿写任务，尚未验证跨生成模型、跨题材、自由生成、润色或人工编辑后的泛化。
- 按**书**划分避免同一本书同时进入训练和测试，但目前没有独立作者 ID，不能保证不同书的作者不重叠。
- 测试集包含同一配对的原文与仿写文本，样本并非完全独立；现有逐段 bootstrap 区间不能替代按书/配对分组的置信区间。
- 词汇分支明显强于句法分支；不能从当前结果推断模型学到了稳定的“AI 写作本质特征”。
- MIT 许可证只覆盖本仓库代码。原文语料及衍生数据的许可和再分发权限**尚未在仓库中证实**；复用或继续公开前应核对来源和授权。详见 [数据说明](docs/DATA.md)。
